# Charlita — tu español, poco a poco

Offline-first Spanish learning PWA. Full design and rebuild instructions: `spanish-app-spec.md`.

## Put it on your iPhone/iPad (GitHub Pages, ~5 minutes, once)
1. Go to github.com → **New repository** → name it `charlita` → Public → **Create**.
2. On the new repo page click **uploading an existing file**. Drag in **everything inside** this folder (not the folder itself) → **Commit changes**.
3. Repo **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**.
4. After about a minute your app is at `https://<your-username>.github.io/charlita/`.
5. On the iPhone, open that link **in Safari** → Share → **Añadir a pantalla de inicio**. Open it once while online; after that it works in airplane mode. Repeat on the iPad.

## Updating later
Upload the changed files to the same repo. Next time you open the app online, it shows **"Hay una versión nueva — Actualizar"**. Your progress stays on the device and is never touched by updates.
Backups: **Ajustes → Exportar** (the app will remind you weekly).
